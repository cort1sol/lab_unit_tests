# geometric_lib

## Общее описание решения

`geometric_lib` — это небольшая Python-библиотека для вычисления площади и периметра геометрических фигур: круга, квадрата, прямоугольника и треугольника. Каждая фигура реализована в отдельном файле.

## Модули библиотеки

### circle.py
* `area(r)` — возвращает площадь круга по заданному радиусу `r`.
* `perimeter(r)` — возвращает длину окружности (периметр круга) по радиусу `r`.

### square.py
* `area(a)` — возвращает площадь квадрата по длине стороны `a`.
* `perimeter(a)` — возвращает периметр квадрата по длине стороны `a`.

### rectangle.py
* `area(a, b)` — возвращает площадь прямоугольника по сторонам `a` и `b`.
* `perimeter(a, b)` — возвращает периметр прямоугольника по сторонам `a` и `b`.

### triangle.py
* `area(a, h)` — возвращает площадь треугольника по основанию `a` и высоте `h`.
* `perimeter(a, b, c)` — возвращает периметр треугольника по трем сторонам `a`, `b` и `c`.
